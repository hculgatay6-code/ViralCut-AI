# Security policy / Güvenlik politikası

v18.1 Beta için kapsam ve güvenlik durumu [denetim raporunda](SECURITY_AUDIT.md) yer alır.

Bir güvenlik açığından şüpheleniyorsan teknik ayrıntıları, erişim anahtarlarını veya örnek medyayı herkese açık Issue, PR ya da yorumda paylaşma. Depoda **Security → Report a vulnerability** görünüyorsa onu kullan. Bu seçenek kullanılamıyorsa depo sahibiyle özel iletişim kurup önce güvenli bir iletim kanalı iste. Windows ve uygulama sürümünü belirt.

Use the repository’s **Security → Report a vulnerability** option when available. Otherwise contact the repository owner privately to arrange a secure channel. Keep reproduction material and credentials out of public issues and pull requests.
